Natural feature extraction is the foundation of the photogrammetry process. It identifies distinctive points in images that can be reliably located across multiple photographs
\Common feature extraction algorithms include[cite: 1]:

| Algorithm | Strengths | Weaknesses | Best For |
| :--- | :--- | :--- | :--- |
| **SIFT** | Scale and rotation invariant[cite: 1] | Computationally expensive[cite: 1] | High-quality, general-purpose reconstruction[cite: 1] |
| **SURF** | Faster than SIFT[cite: 1] | Less accurate than SIFT[cite: 1] | Quick prototyping[cite: 1] |
| **ORB** | Very fast, no patent restrictions[cite: 1] | Less robust to viewpoint changes[cite: 1] | Real-time applications[cite: 1] |

## Algorithms

* [SIFT (Scale-Invariant Feature Transform)](#) - Robust feature detection algorithm[cite: 3]
* [SURF (Speeded-Up Robust Features)](#) - Fast feature detection algorithm[cite: 3]
* [ORB (Oriented FAST and Rotated BRIEF)](#) - Efficient alternative to SIFT and SURF[cite: 3]
* [RANSAC (Random Sample Consensus)](#) - Used for outlier rejection in matching[cite: 3]
* [Structure from Motion (SfM)](#) - Algorithm for recovering 3D structure from 2D images[cite: 3]
* [Multi-View Stereo (MVS)](#) - Dense reconstruction algorithm[cite: 3]
* [Bundle Adjustment](#) - Optimization technique for camera poses and 3D points[cite: 3]
* [FLANN (Fast Library for Approximate Nearest Neighbors)](#) - Fast matching algorithm for feature descriptors[cite: 3]
